# ROSTR for OpenClaw — Claude Project Setup

## Step 1: Create the Project
1. Go to https://claude.ai/projects
2. Create a new project
3. Name: "ROSTR OpenClaw Agent"
4. Paste `system-instructions.md` content into "System Instructions"

## Step 2: Upload Knowledge
Upload the `knowledge/` directory files to the project knowledge base.

## Step 3: Deploy
Follow the OpenClaw setup in `~/rostr-openclaw/openclaw/` to configure your agent.
