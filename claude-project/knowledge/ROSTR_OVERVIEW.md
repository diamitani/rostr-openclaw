# ROSTR Framework Overview

## The Four Layers

### PAL (Prompt Abstraction Layer)
Transforms natural language intent into strict agent runtime manifests.
1. Intent Extraction
2. Context Injection
3. Semantic Enhancement
4. Runtime Compilation
5. Output Routing

### RAG DAL (Dynamic Acquisition Layer)
Autonomous multi-pass retrieval with source credibility.
- Tier 1 (1.0): Academic, official docs
- Tier 2 (0.75): Editorial, verified news
- Tier 3 (0.40): Community, UGC

### NPAO (Navigate, Prioritize, Allocate, Orchestrate)
5D phase taxonomy + 4D priority scoring for intelligent task routing.

### Rostr Hub
Persistent Reference Hub for state, context, and knowledge.
