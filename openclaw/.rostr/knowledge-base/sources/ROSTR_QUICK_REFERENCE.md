# ROSTR Quick Reference

## PAL Pipeline
1. **Extract** intent (verb + object + domain)
2. **Inject** context from Hub
3. **Enhance** (expand ambiguity, add precision)
4. **Compile** into runtime manifest
5. **Route** to execution layer

## 5D Phases
- **PreD** — Is this worth building?
- **Design** — What exactly are we building?
- **Development** — Does it work?
- **Deployment** — Is it safe to ship?
- **Debugging** — What broke and why?

## Priority Score
(Phase_Urgency × 0.35) + (Dependency_Impact × 0.30) + (Business_Impact × 0.25) + (Resource_Efficiency × 0.10)

## Source Tiers
- Tier 1 (1.0): Academic, official docs
- Tier 2 (0.75): Editorial, verified news
- Tier 3 (0.40): Community, UGC

## State Levels
Session → Project → Organization → Agent
